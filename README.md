# Recharge (demo)

A working prototype for the UCL SENDtech Challenge. Pupils aged 9–12 rate the places and moments of their school day on a battery; staff see heatmaps, drift alerts and safeguarding flags.

**All data is fictional.** Everything is saved only in the browser that opens the page.
