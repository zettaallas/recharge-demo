# Recharge (demo)

A working prototype for the UCL SENDtech Challenge. Pupils aged 9–12 rate the places and moments of their school day on a battery; staff see heatmaps, drift alerts and safeguarding flags.

**All data is fictional.** Everything is saved only in the browser that opens the page.

## Try it

- Pupil: class code `6B-K4P`, any name, PIN `1234`
- Staff: `demo@recharge.test` / `demo1234` (also `senco@`, `keyadult@`, `dsl@recharge.test`, same password)

The whole app is one file, `index.html` (React 18, loaded from cdnjs). The optional AI features only work when the page is opened inside claude.ai.

## Editing

`index.html` is the whole app; edit it directly. Before you start, run `git pull --rebase` (or press "Fetch/Pull" in GitHub Desktop) so you have the latest version, and pull again before you push. Editing on github.com with the pencil icon is fine for small changes.
